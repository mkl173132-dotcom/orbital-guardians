# نگهبانان مدار — نسخه سه‌بعدی

این پروژه یک بازی مرورگری سه‌بعدی با Three.js است: صفحه شروع، کره زمین با بافت، کنترل چرخش و زوم، انتخاب نقطه استقرار، انتخاب منطقه مأموریت خیالی، سه تجهیز قابل اجرا، مسیر پرواز، افکت پایان مأموریت، امتیاز، مصرف و شارژ انرژی و گزارش رویدادها.

## اجرا
- برای استفاده از ماژول‌های JavaScript، پروژه را از طریق سرور محلی اجرا کنید؛ باز کردن مستقیم `index.html` با `file://` ممکن است ماژول‌ها را مسدود کند.
- در پوشه پروژه:
  - `python -m http.server 8080`
  - سپس در مرورگر `http://localhost:8080` را باز کنید.
- بافت‌های زمین و کتابخانه Three.js از CDN بارگیری می‌شوند، بنابراین اجرای اولیه به اینترنت نیاز دارد.

## انتشار روی سایت
تمام پوشه `orbital_guardians_pro` را روی هاست استاتیک یا سرویس میزبانی وب آپلود کنید؛ `index.html` باید در ریشه مسیر منتشرشده باشد.

## نکات
- این یک نمونه اولیه فرانت‌اند است و ذخیره‌سازی حساب/پیشرفت یا سرور بازی ندارد.
- کشورها فقط نشانگرهای نمایشی با مختصات تقریبی هستند؛ مناطق مأموریت آلفا/بتا/گاما خیالی‌اند. مسیرها و برخوردها افکت بازی‌اند و مدل فیزیکی، هدف‌گیری واقعی یا راهنمای عملیاتی نیستند.
- تجهیزات «نگهبان-۱»، «پهپاد دیده‌بان» و «موشک خیالی سپهر» مدل‌های ساده و ساختگی‌اند؛ این پروژه مدل واقعی خرمشهر یا سامانه سلاح واقعی را بازسازی نمی‌کند.
- برای نسخه تولیدی، بهتر است بافت‌های مورد استفاده و مجوز آن‌ها بررسی و در صورت نیاز در هاست خود میزبانی شوند.
